# Governance

MediaMTX Connect is a single-maintainer project.

## Decision making

[@bcanfield](https://github.com/bcanfield) is the project maintainer and has
final say on all changes, including feature direction, architecture, releases,
and what gets merged.

Decisions are made in the open, through GitHub issues and pull requests.
Anyone is welcome to open an issue to propose a change, report a bug, or ask a
question, and to open a pull request to propose an implementation. Discussion
happens on the issue or pull request itself.

There is no formal voting process. The maintainer reviews proposals and
contributions, weighs feedback from the community, and makes the final call.
